# YGO Lua 学习平台

[English README](README_EN.md)

一个面向游戏王（Yu-Gi-Oh!）卡片效果脚本的本地交互式学习项目。项目使用原生 HTML、CSS 和 JavaScript，不需要构建工具或第三方依赖。

## 项目内容

| 文件 | 作用 |
| --- | --- |
| `index.html` | 学习平台主页、课程卡片、总进度和课程排序 |
| `Lua-交互式学习平台.html` | Lua 基础交互课程 |
| `YGO-Lua-从第一张卡开始.html` | 第一阶段：从基础卡片脚本开始 |
| `YGO-Lua-第二阶段发动与处理.html` | 第二阶段：发动与处理 |
| `YGO-Lua-第三阶段代价与发动.html` | 第三阶段：代价与发动 |
| `YGO-Lua-第四阶段区域与筛选.html` | 第四阶段：区域与筛选 |
| `YGO-Lua-第五阶段取对象与处理.html` | 第五阶段：取对象与处理 |
| `YGO-Lua-第六阶段属性筛选.html` | 第六阶段：属性筛选 |
| `YGO-Lua-第七阶段卡组检索.html` | 第七阶段：卡组检索 |
| `YGO-效果脚本实验室.html` | 效果脚本实验和测试页面 |
| `progress-sync.js` | 将课程进度摘要同步到主页 |
| `YGO-Lua-课程代码规范.md` | 页面结构、进度数据和代码规范 |
| `网页结构.txt` | 项目结构记录 |

## 使用方法

1. 直接用现代浏览器打开 `index.html`。
2. 从主页选择课程，按课程页面中的观察、测验和练习完成学习。
3. 主页会保存课程进度。课程卡片可以直接拖动调整顺序。
4. 使用“导出进度”备份数据，换设备或清除浏览器数据后可用“导入进度”恢复。

如需本地开发，也可以启动静态服务器：

```powershell
python -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000/`。基本的离线使用不需要启动服务器。

## 课程排序

主页拖动后的课程顺序保存在浏览器的 `localStorage` 键 `ygo-learning:course-order:v1` 中。点击“恢复课程顺序”只会删除自定义排列，不会删除课程学习进度。

## 进度数据

每个课程页面保留自己的详细记录，并通过 `progress-sync.js` 发布主页需要的摘要。主页摘要使用 `progress:{courseId}`，课程私有记录使用各页面自己的键。数据只保存在当前浏览器中，不会自动上传服务器。

## 开发约定

- 修改课程页面后，保留页面中的课程元数据和 `progress-sync.js` 引用。
- 新课程应提供唯一的 `course-id`、阶段编号、进度键和课程描述。
- 课程标题只写课程名称，课程序号由导航或主页显示。
- 保持文件使用 UTF-8 编码。
- 修改后至少用浏览器打开主页和受影响课程，检查导航、进度、练习和导入导出功能。

详细规范请参阅 `YGO-Lua-课程代码规范.md`。

## 许可证与说明

本项目是个人学习和教学辅助项目。项目中的脚本示例用于理解 YGO Lua 的结构和 API；练习页面的代码检查属于文本结构检查，不等同于真实决斗引擎测试。
